clash节点

clash节点是面向个人与小团队的机场订阅服务页，帮助你按设备数量和流量需求选择套餐，并在 Windows、macOS、Android 与 iOS 上完成客户端配置。页面说明订阅如何导入、线路如何区分，以及连接前需要核对的事项。

品牌简介

clash节点把「订阅」和「客户端」分成两步：订阅决定可用流量、同时在线设备数和线路类型；客户端负责在本机读取订阅并选择节点。基础线路适合网页与办公，旗舰版增加流媒体与游戏向线路，团队版提高设备上限与可用流量。

本页为产品说明，不展示用户评分或第三方评测。下载与订阅入口仅使用页内锚点，请在已登录的账户中心获取属于自己的订阅地址。

适合先确认的三件事

  • 常用设备是电脑、手机还是两者都要。
  • 每月大致流量，以及是否需要多人共用。
  • 主要用途是网页办公、流媒体还是低延迟游戏。

确认后再选套餐，避免为用不到的设备数付费。

使用场景

跨境办公与资料查阅

远程协作、云文档和海外网站访问对稳定性要求高于峰值速度。基础版的普通线路节点池即可覆盖邮件、文档和一般浏览；若同一网络下有多名同事，应改看团队版的设备上限。

流媒体与游戏

旗舰版标明全节点原生流媒体解锁，并提供 IPLC 专线游戏加速优化。流媒体更在意线路解锁能力，游戏更在意延迟波动。两者不要混用「流量更大就一定更快」的判断，应先看线路类型。

家庭或项目组共用

一台路由或一个桌面客户端再分享给多个手机，会计入同时在线设备。基础版 3 台、旗舰版 5 台、团队版 20 台。超出后新设备会连不上，而不是悄悄降速，因此人数增长前应先升级套餐。

客户端选择

客户端选择是使用 clash节点的关键一步。订阅本身不能单独联网，必须由支持 Clash 规则的客户端拉取。请按操作系统挑选，不要在手机上安装桌面安装包。

Windows

优先使用 Clash for Windows 或 Clash Verge。导入订阅后打开系统代理，浏览器与大部分桌面软件会跟随。需要分流时，在客户端里保留规则模式，而不是全局模式。

Windows 操作说明

macOS

ClashX 或 Clash Verge 都可读取同一条订阅。菜单栏图标变色只表示客户端在运行，不表示当前节点可用，仍需在节点列表里手动测延迟后再连接。

macOS 操作说明

Android

选择可持续后台运行、支持订阅链接的 Clash 客户端。首次导入后允许 VPN 权限。省电策略若冻结后台，表现为隔几分钟断开，应在系统设置里取消对该应用的休眠。

Android 操作说明

iOS

使用支持 Clash 或同类规则的 App，通过账户中心复制订阅链接添加。iOS 对后台限制更严，锁屏后短时断开通常是系统策略，而不是流量已经用尽。

操作说明

从选购到连上

  1. 在套餐区选定基础版、旗舰版或团队版，并决定月付或年付。
  2. 在账户中心复制专属订阅地址，不要把地址发到公开群组。
  3. 按上一节安装对应系统的客户端，选择「从 URL 导入」。
  4. 更新订阅，按延迟或用途挑选节点，再开启系统代理或 VPN 开关。
  5. 用浏览器打开常用网页做一次连通检查；流媒体与游戏请改选旗舰版对应线路。

日常维护

节点列表会调整。客户端里执行一次订阅更新即可，不必重装软件。更换设备时，先在旧设备断开，再在新设备导入，以免占用同时在线名额。

流量接近套餐上限时，账户中心会显示剩余额度。用尽后当月无法继续加速，可等下个结算日或升级到更高流量套餐。

常见问题

clash节点和单独的加速器有什么差别？

clash节点以机场订阅交付线路和流量，加速发生在你自己安装的客户端里。它不是只针对某一款游戏的独立加速器。旗舰版里的 IPLC 专线更偏向游戏延迟，基础版则是普通线路节点池，适合一般网页。

官网下载客户端时要注意什么？

按操作系统进入本页客户端选择，再从账户中心给出的入口获取安装包。不要使用来源不明的修改版。同一条订阅可在额度内的多台设备导入，但同时在线数不能超过套餐上限。

订阅地址泄露了怎么办？

立即在账户中心重置订阅链接，旧地址会失效。已导入旧地址的客户端需要重新粘贴新地址并更新。重置不会清空当月已用流量，只更换访问凭证。

为什么更新订阅后仍然连不上？

先确认账户未过期、流量未用尽，再检查本机时间是否准确。然后在客户端切换另一条节点。若只有某一地区不可用，通常是该线路维护，而不是整个订阅失效。旗舰版用户可走优先工单，团队版可联系客户经理。

基础流媒体和全节点解锁有何不同？

基础版只承诺基础流媒体，部分平台或地区片库可能打不开。旗舰版写明全节点原生流媒体解锁，选节点时仍应挑选标注流媒体的线路。解锁能力不提高流量配额，观看高清会更快消耗 300GB 或对应套餐额度。

团队版的定制路由适合谁？

适合需要 20 台设备同时在线、每月约 1000GB，并且希望按部门或项目指定出口的小组。定制路由在开通后由客户经理确认网段与用途，不包含在基础版和旗舰版中。个人用户若只有几台设备，旗舰版通常足够。
